
# 63sats VulnBank – Web Application VAPT

## Overview

A **Web Application Vulnerability Assessment and Penetration Testing (VAPT)** project conducted on the VulnBank application in a controlled laboratory environment.

## Objective

To identify, validate, and document common web application vulnerabilities and provide appropriate remediation recommendations.

## Tools Used

* Kali Linux
* Burp Suite
* Gobuster

## Vulnerabilities Identified

* SQL Injection
* Authentication Bypass
* Stored XSS
* CSRF
* Parameter Tampering
* Insecure Session Management
* Unrestricted File Upload
* IDOR
* Insecure HTTP / Clear-text Credentials
* Information Disclosure
* Clickjacking
* Lack of Rate Limiting

## Methodology

**Reconnaissance → Enumeration → Vulnerability Identification → Validation → Risk Assessment → Remediation**

## Learning Outcomes

* Practical web application security testing
* Burp Suite and Gobuster
* Vulnerability identification and validation
* VAPT methodology
* Security risk analysis and remediation

## Disclaimer

This project was performed only in an **authorized, controlled laboratory environment** for educational purposes. Do not test systems without explicit permission.
